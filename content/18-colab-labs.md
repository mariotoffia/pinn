# 18 — Colab Lab Index

Every **"open in Colab"** notebook from the whole path, collected here and grouped by the
chapter it belongs to. Use this page to find a runnable lab fast, or to work the hands-on
lane without re-reading the chapters.

How to run any of them:

1. **Click the badge.** The notebook opens in Google Colab (you need a free Google account).
2. Choose **Runtime ▸ Run all**. The code runs on Google's machine, not yours.
3. Where a row says a **GPU helps**, take one for free via **Runtime ▸ Change runtime type**.
   Everything else is fine on Colab's default CPU.
4. A Colab session **forgets everything when it disconnects** — if you edited something you
   want to keep, use *File ▸ Save a copy in Drive*.

Some notebooks start with a `pip install` cell — run it like any other cell. Where a repo
carries no license file, run the notebook in place rather than copying it into your own work.

chapters themselves — each link carries its summary as a markdown link title, which is also
the tooltip you see when hovering any Colab badge. Edit the summary at the link, not here.)*
